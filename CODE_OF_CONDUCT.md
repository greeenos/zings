# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

The full text is available at: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be kind, be patient, assume good faith, and help make Zings a welcoming project for everyone regardless of background or experience level.

## Reporting

If you witness or experience behavior that violates the Contributor Covenant, please contact the project maintainer privately:

- **Email**: adamgreen629@gmail.com (subject: `[zings conduct]`)

Reports will be handled confidentially. The maintainer will review the report and respond with whatever action seems appropriate, which may range from a private conversation to a permanent ban from project spaces.

## Scope

This Code of Conduct applies to all project spaces — the GitHub repository (issues, PRs, discussions, commit messages), as well as any official communication channels — and to anyone representing the project in public.
